# 原生条件语义下的 Omni PoC

| 元素 | 固定安排 |
|---|---|
| 要验证什么 | 同一个联合训练模型，在 folding 和 design 上分别优于未训练原版 |
| 修复 | 保留相对 motif 条件；直接调用原版 sampler；反馈只进入 denoiser；不做错误的绝对坐标硬投影、不关闭原版对齐 |
| 模型 | 原版权重起步，冻结 trunk；全参数训练 diffusion、conditioning、反馈和序列头；无 LoRA |
| 统一目标 | 原版 sigma 加权坐标 MSE + smooth-lDDT + masked identity CE + 原版教师 MSE；两种任务只变观察字段；CE 权重用更新前 16 个 batch 的梯度尺度确定后冻结 |
| 数据 | 已核实的官方训练集 128 条，独立验证 16 条；复用缓存，只把被误解释的相对条件恢复原语义 |
| 训练 | 一次、400 updates，每次 4 folding + 4 design；固定最终共享 checkpoint；不训练对照或消融 |
| 开训前检查 | 2 条验证蛋白 × 两任务完整生成，检查有限坐标和严重断链；不比较逐坐标相等；保存真实初始化权重 |
| 评测 | 原有 8 个公开 folding 验证结构 × 5 次；6 个 RFdiffusion 任务 × 4 骨架 × 8 MPNN/ESMFold 序列；复用已经核验的原版结果，保留全部分母 |
| 标准 | Folding best-of-5 CA-lDDT、TM-score；design 同一序列 CA RMSD≤2Å、motif backbone RMSD≤1Å、pLDDT≥70、pAE≤5，8 条中至少 1 条满足 |
| 记录 | W&B + JSONL；源码/数据/权重 hash、分任务 loss 和梯度、初始化/中间/最终验证、checkpoint、失败尝试也计入 GPU 用量 |
| 解读 | 两任务独立提高才支持这个 PoC；目标/任务级配对区间；区间跨零就不能确认提高 |

这是已被查看过的修复回归/探索性评测子集，不是假装全新的确认性测试。
Folding 是作者公开验证名单，不是尚未公开的 Figure 15 测试集。
Design 指标衡量 MPNN 重设计后的骨架可设计性，不单独证明序列头能力。
不设置生成质量下降自动停训；开训前实现检查与训练中的有限数值检查分别记录。
失败结果保留；如果出现执行错误，保留更新后的权重/优化器状态后继续，不能静默从零重训。
修复消除了已确认的实现差异，但不能预先保证训练后提高。
